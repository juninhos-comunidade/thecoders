## Sobre o projeto

O **theCoders Cases** é um simulador de cases em grupo para candidatos
iniciantes em TI (Estagiário/Júnior), com avaliação de desempenho apoiada por
IA ao final de cada simulação. Veja [`arquitetura.md`](./arquitetura.md) para
a visão completa do domínio e [`frontend.md`](./frontend.md) para o
detalhamento de como isso foi implementado na interface.
